## Transaction API

### `transaction(fn, stores)`

Execute a function within a transaction. Changes to the specified stores are kept if the function succeeds, or reverted if it throws an error.

- **Parameters:**
  - `fn: () => T` - Function to execute in the transaction (can be async)
  - `stores: Store<any>[]` - Array of stores to include in the transaction
- **Returns:** The return value of `fn` (or a Promise if `fn` is async)
