# Transactions

Transactions allow you to update stores with automatic rollback on error. If the transaction function throws an error, all store changes are reverted to their values before the transaction started. Supports sync and async functions.

## Use cases

Transactions are useful when you need to:

- **Update multiple stores together**: Ensure all stores are updated or none are
- **Rollback on error**: Automatically revert changes if something goes wrong

## Basic usage

Use the `transaction` function with an array of stores you want to revert in case of error:

```ts twoslash
// @noErrors
// @filename: node_modules/stav/index.d.ts
export { create } from "../../src/create";
export { transaction } from "../../src/transaction";

// @filename: index.ts
// ---cut---
import { create, transaction } from "stav";
//               ^^^^^^^^^^^

const store1 = create({ count: 0 });
const store2 = create({ total: 0 });

transaction(() => {
  store1.set({ count: 1 });
  store2.set({ total: 100 });
}, [store1, store2]);

console.log(store1.get());
// @log: { count: 1 }
console.log(store2.get());
// @log: { total: 100 }
```

If the transaction function completes successfully, all changes are kept. If it throws an error, changes are reverted.

## How it works

When you call `transaction`, stav creates a restore point by capturing the current state of all specified stores. Inside the transaction, state updates are applied optimistically. If the function throws an error, stav restores all specified stores to their original values from the restore point.

```ts twoslash
// @noErrors
// @filename: node_modules/stav/index.d.ts
export { create } from "../../src/create";
export { transaction } from "../../src/transaction";

// @filename: index.ts
// ---cut---
import { create, transaction } from "stav";

const store = create({ count: 0 });

try {
  transaction(() => {
    store.set({ count: 1 });
    console.log(store.get());
    // @log: { count: 1 }
    throw new Error("Something went wrong");
  }, [store]);
} catch {}

console.log(store.get());
// @log: { count: 0 }
```

## Async transactions

Transactions work seamlessly with async code:

```ts twoslash
// @noErrors
// @filename: node_modules/stav/index.d.ts
export { transaction } from "../../src/transaction";

// @filename: node_modules/stav/object.d.ts
export { create } from "../../src/middleware/object";

// @filename: index.ts
// ---cut---
import { transaction } from "stav";
import { create } from "stav/object";

const store = create({
  loading: false,
  user: null,
  profile: null
});

await transaction(async () => {
  store.assign({ loading: true });

  const userResponse = await fetch("/api/user");
  const user = await userResponse.json();

  store.assign({ user });

  const profileResponse = await fetch("/api/profile/" + user.id);
  const profile = await profileResponse.json();

  store.assign({ profile, loading: false });
}, [store]);
```

If the promise rejects at any point, the store is reverted to its original value.
